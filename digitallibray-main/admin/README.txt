DIGITAL LIBRARY ADMIN PANEL

1. Create a Supabase project.
2. Run /supabase.sql in Supabase SQL Editor.
3. Create an admin user in Supabase Authentication > Users.
4. Put Project URL and anon/publishable key in /admin/js/supabase.js.
5. Open /admin/login.html through a local/static web server.

Implemented: auth, protected admin pages, dashboard, resource CRUD, PDF/image upload, filters, responsive sidebar, dark mode, website/settings/media/announcement UI foundations.
